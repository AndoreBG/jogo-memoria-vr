# Jogo da Memória VR 🌐 ![Static Badge](https://img.shields.io/badge/status-%20finalizado-green)

Jogo da memória web feito com A-Frame, pensado para ser jogado em desktop ou mobile pelo navegador.

O jogador deve encontrar 8 pares de cartas com frutas. As cartas ficam distribuídas em uma grade 4x4 posicionada em semi círculo, criando uma experiência mais imersiva.

## Como jogar

1. Clique em **Iniciar**.
2. Mire o retículo central em uma carta.
3. No desktop, pressione **Espaço** para selecionar.
4. No mobile, mire na carta, pressione a tela e segure por 1 segundo.
5. Encontre todos os pares com o menor número de tentativas possível.

## Tecnologias

- HTML
- JavaScript
- A-Frame
- Canvas para texturas das cartas e fundo

## Recursos

- 8 pares de cartas
- Distribuição em semi círculo de 135 graus
- Controle de câmera com mouse no desktop
- Controle por giroscópio no mobile
- Retículo central para seleção
- Contador de tentativas
- Tela inicial com regras
- Tela final com resultado e botão de reiniciar
